La infraestructura cloud es una extensión natural de mi trabajo con redes, entornos Windows y control de accesos. Quiero profundizar en cómo se conectan los servicios, cómo se administran los permisos y cómo se valida la seguridad de sus configuraciones.

## Áreas de interés

| Área | Tecnologías y prácticas |
|---|---|
| **Redes virtuales** | Azure VNet, subredes, rutas y conectividad |
| **Identidades y acceso** | Microsoft Entra ID, RBAC y mínimo privilegio |
| **Seguridad de redes** | Network Security Groups, firewall y segmentación |
| **Entornos híbridos** | Conectividad entre infraestructura local y servicios cloud |
| **Monitoreo** | Diagnóstico de red, registros y validación de configuraciones |
